Release Security 13 September 2026 · v0.4.35

Every currency in the world. And a fee you can check.

Version 0.4.34 shipped with 14 regional stablecoins. Version 0.4.35 ships with 161. That is the headline. The more useful change is quieter: the network stopped guessing what things cost.

0.4.34 → 0.4.35 Wallet and miner ship together
01
Currencies

161 currencies, from one list

The chain now mirrors every circulating currency: the Kyrgyz som, the Ethiopian birr and the Bhutanese ngultrum it already had, joined by the Indian rupee, the Brazilian real, the Nigerian naira, the Vietnamese dong and 140 others.

Six of them have no ISO 4217 code at all, so no currency feed carries them: the Transnistrian ruble, Somaliland shilling and Abkhazian apsar — issued by states most of the world does not recognise, and circulating anyway — and the Kiribati dollar, Tuvaluan dollar and Faroese króna, local issues pegged one-to-one to the Australian dollar and Danish krone.

They are on the chain because people use them, not because a committee approved them.

All 161 come from a single table, and the miner, the wallet and the exchange are generated from it. Previously each kept its own copy, which is how ten currencies once ended up formatted with the wrong number of decimal places. One list now, one place to fix.

02
Honesty

Some currencies ship with no price — on purpose

Eight of the 161 arrive with no exchange rate attached: the two Cuban pesos, the North Korean won, and the six unrecognised currencies.

This is deliberate. The Cuban convertible peso was abolished in 2021 and has only its old peg. North Korea's official rate of 900 won to the dollar is roughly nine times away from what anyone actually trades at. Nobody quotes the rest.

Rather than ship a number that looks authoritative and is fiction, the miner ships nothing and says so.

No DAI/aiKPW rate: nothing is quoted on the P2P book and no forex rate is available. Be the first to place an order.

8 ship with no rate Price arrives when someone opens the market
03
Fees

Job fees now come from the market

This is the change most people will feel. Before, each currency had a fee rate written into the software — a number that was correct on the day it shipped and drifted from that moment on.

Now the anchor is fixed and simple: one AI token costs one μDAI, and μDAI is the smallest unit there is, so that is also the floor. A job paid in DAI costs exactly the tokens it used.

Paying in anything else is a conversion, and the network already knows the only rate that matters — the one people are trading at. It looks, in order:

  1. The order book. Is anyone quoting DAI against your currency? Use that.
  2. A bridge. No direct market, but both sides trade against USDT, USDC, BTC, ETH or SOL? Go through it.
  3. Forex. Nobody quotes it at all? Fall back to the published rate.
  4. Nothing. Say so, and invite the first order.

You can see which of the four answered — the fee comes back labelled with its source. A price you can check beats a price you have to trust.

1 token = 1 μDAI Source labelled on every fee No invented rates
04
P2P

Orders are properly signed now

A real security fix, and a breaking one.

When you created a sell order, your wallet only signed which side and how much. The price, the currency and the address your payment goes to all travelled unsigned. Anything sitting between your wallet and the node could rewrite the price, or swap the payout address for its own, and the signature still checked out.

Taking an order had the same hole: the address your funds land on was not signed either.

Both now sign the complete order. There is deliberately no fallback to the old format — accepting one would leave the same door open. The wallet and the miner must be updated together. An old wallet talking to a new node will be refused.

Full payload signed No old-format fallback Wallet + miner together
05
Security

What we locked down

A security pass on the miner and the phone wallet. In plain terms:

  • Nobody can reach into a miner's tools for free. A public endpoint used to run whatever the miner had plugged in — including shell tools — without paying. That door is closed. Search and other tools still run when you pay for a job.
  • A P2P take has to pay the advertised price. Taking an on-chain order used to let the taker name any price. They could empty the seller's escrow for a token. The fill must now match the order.
  • Gossip cannot rewrite the order book. Peers used to accept unsigned order updates, so a fake message could change the payout address or the price on a live listing. Unsigned copies are dropped.
  • A webpage cannot spend your desktop wallet. The miner used to tell the browser any site may POST to localhost. CORS no longer reflects random websites.
  • Balances cannot be debited on a name alone. Every debit now needs a signature bound to a nonce.
  • The phone no longer trusts a random HTTP miner. Discovered peers must be HTTPS, sends do not fail over to a stranger, and skill fees ask before they sign.

Rotate any RPC keys that lived in a committed config.json. That file is no longer tracked.

06
Finding things

A search box, not a strip of 161 buttons

A row of buttons works for 15 currencies. At 161 it is a strip you drag through, with no way to find Bhutan unless you already know it is αιBTN.

Every currency selector — in the phone wallet, in the desktop app, on the exchange — is now a search box. It matches on ticker, country code, currency name and country, so “Bhutan”, “ngultrum”, “BTN” and “αιBTN” all find the same thing.

The market list needed the same treatment. Every currency trades against every other, which took the number of markets from 360 to more than 25,000 — about 3.8 MB if you send them all at once. The list is now paged: 72 KB by default, with filters for the pair you actually want.

Also in this release

Skills, chat, and the desktop app.

Skills that fit the model

52 of 72 shipped skills were being cut off mid-sentence. 182 pointers led to files that were never shipped. The tool picker no longer guesses when it fails.

16 new skills, no API keys

Ritual Chain and MiniMax development skills, adapted to fit. The importer rejects anything that needs an account. Skills are found by description, not only by keyword.

Seven knowledge servers

DeepWiki, Context7, GitMCP, Microsoft Learn, AWS, Cloudflare, Solana and Hugging Face. Every one was tested for anonymous access. None needs an account.

Chat actually finishes

Output is capped, /no_think is not sent to models that do not understand it, raw reasoning no longer leaks, and chat checks for tools before guessing.

Skills tab does not freeze

It used to re-parse the whole page for every skill. Now it loads 24 at a time from a 50 KB response, with a search box.

View Private Key works

If the machine cannot decrypt the key, the app says so — instead of pointing at an encrypted file you cannot read.

Update the wallet and the miner together

0.4.35 is a coordinated upgrade. Adding currencies changes the chain's starting state, so every node moves together — a node running the old currency list will reject transactions the new one accepts.

The signed-order change is breaking on its own. Update the wallet and the miner at the same time, or orders will be refused. Existing balances carry over.
